# Hospital Policy Assistant (RAG)

A Streamlit chatbot that answers questions about hospital policies, grounded
in your own PDF documents via retrieval-augmented generation (FAISS +
Groq-hosted LLM).

## Repo structure

```
.
├── app.py                          # Streamlit app (retrieval + Groq generation)
├── ingest.py                       # One-time script: PDFs -> chunks -> FAISS index
├── requirements.txt
├── .gitignore
├── .streamlit/
│   └── secrets.toml.example        # Copy to secrets.toml, fill in your key (not committed)
├── hospital_knowledge_base/        # Your policy PDFs, organized in subfolders by department
└── faiss_index/                    # Generated by ingest.py: index.faiss, index.pkl, metadata.jsonl
```

## 1. Setup

```bash
git clone <your-repo-url>
cd <your-repo>
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## 2. Get a Groq API key

Free at [console.groq.com](https://console.groq.com) — create an API key.

## 3. Build the index

Place your PDFs under `hospital_knowledge_base/<department>/*.pdf`, then:

```bash
python ingest.py
```

This creates `faiss_index/` with the vector index and `metadata.jsonl`
(department, source file, page, text for every chunk).

## 4. Run locally

```bash
export GROQ_API_KEY="your_key_here"     # Windows: set GROQ_API_KEY=your_key_here
streamlit run app.py
```

Open the local URL Streamlit prints (usually `http://localhost:8501`).

## 5. Deploy on Streamlit Community Cloud

1. Push this repo to GitHub (see `.gitignore` — commit `faiss_index/`, skip the raw PDFs).
2. Go to [share.streamlit.io](https://share.streamlit.io), connect your GitHub repo, set the main file to `app.py`.
3. In **Settings → Secrets**, add:
   ```toml
   GROQ_API_KEY = "your_key_here"
   ```
4. Deploy. The app loads `faiss_index/` from the repo at startup — no PDF re-processing needed on the server.

## Notes

- To rebuild the index after adding/changing PDFs, rerun `python ingest.py` locally and push the updated `faiss_index/` folder.
- Department filter in the sidebar comes from each PDF's top-level subfolder name under `hospital_knowledge_base/`.
- Default model is `llama-3.3-70b-versatile` on Groq — change `GROQ_MODEL` in `app.py` if you want a different one.
